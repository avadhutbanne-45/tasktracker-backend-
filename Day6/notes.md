# Day 6 — Connecting React with Django API

## Work Completed

* Connected the existing React Task Tracker frontend with the Django backend.
* Used the `fetch()` API for frontend-backend communication.
* Retrieved tasks from Django using GET.
* Added new tasks using POST.
* Updated task status using PUT.
* Deleted tasks using DELETE.
* Verified JSON responses from the Django API.
* Verified that task data is stored and retrieved from the SQLite database.
* Tested the React and Django integration successfully.

## API Used

* GET `/api/tasks/`
* POST `/api/tasks/`
* PUT `/api/tasks/<id>/`
* DELETE `/api/tasks/<id>/`

## Result

The React Task Tracker frontend is successfully connected to the Django backend, and task CRUD operations are working through the Django API.
