# Week 4 — Day 2: Django Fundamentals

## Objective

To understand Django project structure, applications, URLs, and views.

## Work Completed

* Created a Django project named `tasktracker`.
* Created a separate Django application named `tasks`.
* Registered the `tasks` application in `INSTALLED_APPS`.
* Created a basic Django view.
* Created application-level URL configuration.
* Connected the application URLs to the main project URLs.
* Tested the request-response flow using the browser.

## Request-Response Flow

Browser Request
→ Project URL
→ App URL
→ View
→ HTTP Response

## Result

The Django project and Task Tracker application were successfully created. The URL routing was connected to a Django view, and the backend successfully returned a response in the browser.
