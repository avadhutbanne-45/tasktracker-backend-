# Week 4 — Day 3: Request Handling

## Objective

To understand and handle GET, POST, PUT, and DELETE requests using Django.

## Work Completed

* Created a Django API endpoint at `/api/tasks/`.
* Implemented GET request handling.
* Implemented POST request handling.
* Read JSON data from the request body.
* Implemented PUT request handling.
* Implemented DELETE request handling.
* Returned JSON responses from the Django backend.
* Tested the requests using the browser and Postman.

## API Endpoint

`/api/tasks/`

## HTTP Methods

GET → Retrieve/request data

POST → Send/create data

PUT → Update data

DELETE → Delete data

## Testing

GET, POST, PUT, and DELETE requests were tested successfully.

## Result

The Django backend successfully handled the required HTTP requests and returned JSON responses.
