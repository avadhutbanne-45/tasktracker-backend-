# Week 4 — Day 1

## Python Backend Setup

### Objective

To set up the Python backend development environment for the Task Tracker project.

### Work Completed

1. Created the Week 4 backend folder.
2. Created a Python virtual environment using `venv`.
3. Activated the virtual environment.
4. Verified pip.
5. Upgraded pip.
6. Installed Django.
7. Verified the Django installation.

### Python Version

Python 3.14.7

### Django Version

Django 6.1.1

### pip Version

pip 26.2.1

### Commands Used

```text
python --version
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip --version
python -m pip install --upgrade pip
python -m pip install django
python -m django --version
python -m pip list
```

### Day 1 Result

The Python backend development environment was successfully configured. The virtual environment, pip, and Django installation were completed and verified successfully.
